06 · Text ↔ DNA encoding lab

Reversibly encode digital text as A/T/G/C symbols. This is data encoding, not biological DNA design.

Encode

Text → DNA

Encoded DNA appears here.
Format: prefix “DNATXT1”, then a 32-bit length header and UTF-8 bytes. Each 2-bit pair maps 00→A, 01→C, 10→G, 11→T. The prefix is metadata, not part of the encoded bases.
Decode

DNA → Text

Decoded text appears here.

Paste only the DNA bases from the encoder output. The decoder checks the length header and UTF-8 data.
